## Adding lesson N
1. Extract text with pypdf (TB pages + key, WB pages + key). Romanization removed.
2. Add the vocabulary list to `tools/gen_forms.py` (irregular flag by hand) → run it.
3. Write `src/lN/*.js` following L1 (shifts A/B/C, 10 scenes each, 6 CCTV, pool, reads, cards, `fixSkills`, `formTpl`).
4. Add audio: `ffmpeg -i in.mp3 -vn -map_metadata -1 -ac 1 -b:a 64k out.mp3` (-vn drops cover art: 4× smaller) → `audio/lN/`; add to `audio_manifest.js`; give new files in `files` on publish (earlier files stay).
5. Add upgrades for that lesson in `cast.js` (bonus/perk) if new ones unlock.
6. `./build.sh`, Playwright run, publish the page with `files`: the new/changed `lessons/lN.js` + the new `audio/lN/*` (files left out stay). Republish the same file path / pass the URL from another chat.
7. APK: raise `android/verze.txt` → `python3 -I scripts/build_web.py && bash tools/build_apk.sh` (since 1.26: Java project in `android/src`, tools from npm; see the section *Sync between devices* at the end). Older notes below about apktool / smali / `android/apktool.yml` describe versions up to 1.25.

## Decisions
- Lessons are an accordion (no dropdown): rows in `#lbar` up to the open lesson (with its tabs), then `#main`, then the later lessons in `#ltail`. Tapping the open lesson collapses it (`S.cur.closed`, main hidden). Rows show 3 status dots (TB/WB/game).
- Touch input (friend reported stutter when typing): on-screen keys fire on pointerdown (not click), hold ⌫ repeats; tiles keep their bank buttons in the DOM (only the tray redraws) and register on pointerup; `touch-action: manipulation` on all controls (no iOS double-tap zoom). `tools/run_touch.py` checks fast taps (25 ms keys, 30 ms tiles). The composer itself was correct (node test).
- Flashcards: each vocabulary card shows an example sentence on the back (`examples` map in game_LN.js; book sentences preferred, app-written ones marked ⚠ in the data).
- Header: no clock; streak stamp (출근 + days in a row) + today's progress x/10 (daily goal), then ₩ and theme. Game tab opens straight on Shifts (no 'next task' banner); every activity card has a kind label + one-line explanation. Chat/notice board show the whole text at once; translations appear after the 3 questions.
- App language English; no romanization anywhere; audio not synced with text.
- Textbook = read-only text + end-of-lesson exercises only (user removed the sentence fill-in mode). `gap` fields in textbook data and the gap code in tb.js are unused (fill = false).
